# gaugent 0.1.1

More reliable usage refreshes and fewer unnecessary menu-bar redraws.

## Changes

- Prevent refreshes from hanging when a CLI stops reading input or leaves output pipes open, and reject oversized responses.
- Handle out-of-range provider numbers and invalid reading dates without crashing.
- Keep Claude fallback readings visibly stale after a failed live refresh, so they do not trigger low-allowance warnings.
- Prevent cached allowances from being reused when the CLI does not identify the signed-in account.
- Improve runtime discovery for CLI installations when gaugent is launched from Finder.
- Reuse menu-bar artwork when the displayed allowance has not changed, while continuing to reflect expired and stale readings.

## Installation

Download `gaugent-0.1.1.dmg`, drag gaugent into Applications, eject the disk image, and launch gaugent. Requires macOS 14 or later; supports Apple Silicon and Intel. Install and sign in to Claude Code and/or Codex separately.

## Updating

From gaugent 0.1.0, use Settings → General → Check now. Existing settings and CLI sign-ins are preserved. Manual installation from the DMG is also supported.
