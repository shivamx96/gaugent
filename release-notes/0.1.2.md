# gaugent 0.1.2

See which subscription your remaining allowance belongs to, at a glance.

## Changes

- Add a small O (OpenAI) or A (Anthropic) badge over the menu-bar gauge.
- Show the lowest positive usable allowance, accounting for shared session and weekly limits as well as model-specific and named allowances.
- Continue showing a usable allowance when another subscription or model is blocked, while keeping reached limits visible in the panel.
- Show the provider, allowance window, and reset time in the tooltip without adding more menu-bar text.
- Display positive balances below one percent as `<1%`.
- Handle invalid cached reset dates consistently across supported macOS versions.

## Installation

Download `gaugent-0.1.2.dmg`, drag gaugent into Applications, eject the disk image, and launch gaugent. Requires macOS 14 or later; supports Apple Silicon and Intel. Install and sign in to Claude Code and/or Codex separately.

## Updating

Use Settings → General → Check now. Existing settings and CLI sign-ins are preserved. Manual installation from the DMG is also supported.
