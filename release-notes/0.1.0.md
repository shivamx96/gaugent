# gaugent 0.1.0

The first packaged release of gaugent: Claude Code and Codex subscription allowances in your macOS menu bar.

## Included

- Session and weekly allowances, reset times, and the lowest current allowance in the menu bar.
- Clear status for stale readings, missing tools, signed-out accounts, and reached limits.
- General, Tools, and Advanced settings, including launch at login, appearance, diagnostics, and cache reset.
- Verified in-app update support and a refined app icon.

## Installation

Download `gaugent-0.1.0.dmg`, drag gaugent into Applications, eject the disk image, and launch gaugent. Requires macOS 14 or later; the app supports Apple Silicon and Intel.

Install and sign in to Claude Code and/or Codex separately. Then open the gaugent menu-bar icon. Settings → Tools provides setup and recovery actions.

This first updater-enabled release must be installed manually.

## Updates

Downloads and the signed update feed are publicly accessible; no GitHub account is required. Future releases can be installed through Settings → General → Check now, with optional automatic checks and background downloads.
