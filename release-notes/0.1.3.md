# gaugent 0.1.3

Track your Antigravity allowances alongside Claude Code and Codex.

## Changes

- Add Antigravity quota groups, remaining allowances, and reset times from your signed-in Google account.
- Keep Gemini and third-party model allowances separate, including their five-hour and weekly limits.
- Add a Google “G” badge to the menu-bar gauge when Antigravity supplies the displayed allowance.
- Enable the new provider on upgrade while preserving disabled tools and an all-off preference.
- Check CLI compatibility before reading usage, without starting a model turn or consuming model tokens.

## Installation

Download `gaugent-0.1.3.dmg`, drag gaugent into Applications, eject the disk image, and launch gaugent. Requires macOS 14 or later; supports Apple Silicon and Intel. Install and sign in to Claude Code, Codex, and/or Antigravity separately.

## Updating

Use Settings → General → Check now. Existing settings and CLI sign-ins are preserved. Manual installation from the DMG is also supported.

## Known limitations

- Antigravity readings cover its coding-agent quotas, not Gemini chat or the entire Google AI subscription.
- Antigravity's quota response does not identify the account or plan. Its label shows “Signed in”; readings are not saved between launches or retained after a failed refresh.
- A recent Antigravity CLI is required. Run `agy update` in Terminal if gaugent asks for an update. API-key billing is not supported.
